 ==================================================
ENTERPRISE FRONTEND-FIRST DEVELOPMENT RULES
===========================================

IMPORTANT:

This project will be developed in two phases.

PHASE 1:
Frontend Development

PHASE 2:
Backend Development

While building frontend components, always assume backend APIs already exist.

Never create temporary frontend architecture that requires future refactoring.

All components must be designed so backend integration can be connected later with minimal code changes.

==================================================

================================
